
🚀 IT 인프라 기업 홈페이지 구축을 위한 마스터 프롬프트
[역할 설정] 너는 세계적인 수준의 시니어 풀스택 개발자이자 UI/UX 디자이너야. IT 인프라(서버, 네트워크, 보안 솔루션) 전문 기업의 웹사이트를 현대적이고 세련된 스타일로 구축해야 해.

[핵심 레이아웃 및 내비게이션]

상단 메뉴(GNB): 서비스(Service), 제품(Product), 회사소개(About)로 구성해.

트리형 내비게이션(Sidebar): 상단 메뉴를 클릭하면 왼쪽 사이드바가 해당 카테고리의 '트리 형태'로 변경되어야 해.

서비스 트리: 서버, 네트워크, 스토리지, 컨설팅, 유지보수

제품 트리: RoseHA, LSware (각 하위 항목 포함)

회사소개 트리: 비전과 미션, 연혁, 협력체, 오시는길

고정 프레임 구조: 전체 페이지 리프레시 없이, 사이드바 메뉴 클릭 시 오른쪽의 고정된 메인 프레임(Content Area) 영역의 내용만 매끄럽게 변경되어야 해 (SPA 방식 권장).

[디자인 가이드라인]

톤앤매너: 전체적으로 화이트 톤(Pure White) 기반의 미니멀리즘 디자인. 포인트 컬러는 신뢰감을 주는 Deep Blue(#003366) 또는 테크니컬한 느낌의 Slate Grey를 사용해.

메인 페이지(Hero): 접속 시 IT 인프라의 흐름을 상징하는 고화질 영상 또는 모션 그래픽 배경을 전면에 배치하고, 중앙에 "Connecting the Future, Securing the Infra" 슬로건을 노출해.

UI 특징: 100% 반응형 UI(PC/Tablet/Mobile). 스크롤 시 요소가 부드럽게 나타나는 애니메이션(Fade-in) 적용.

[상세 콘텐츠 반영]

제품(RoseHA): 실시간 데이터 복제, 자동 장애 감지 및 페일오버, 시점 복구 기능을 강조하는 인포그래픽 섹션 포함.

제품(LSware): 서버 보안 브랜드 'Omniguard'의 계정관리(UAC), 권한관리(UCC), 취약점 진단(SecuMS) 모듈을 카드 형태로 소개.

회사소개: 연혁은 세로형 타임라인 레이아웃으로, 협력체는 글로벌 벤더(Dell, HP, Cisco 등) 로고 슬라이더로 구현.

[개발 모드 및 편집 기능 - 핵심 요구사항]

직관적 웹 편집기(Visual Editor): Admin 또는 개발 모드로 접속 시, 웹 화면상에서 직접 텍스트를 클릭하여 수정하고, 이미지를 드래그 앤 드롭으로 교체할 수 있는 CMS 기능을 구현해줘.

기술 스택 추천:

Frontend: React 또는 Next.js (매끄러운 프레임 전환을 위해)

Styling: Tailwind CSS (화이트 미니멀리즘 구현)

Admin/CMS: 직접 편집이 가능하도록 Storyblok 또는 Webflow 스타일의 시각적 편집 인터페이스를 모방하거나, Payload CMS와 같은 Headless CMS 연동 구조로 설계해.

[작업 지시]

먼저 전체적인 사이트 구조(App structure)와 내비게이션 로직을 설계해줘.

화이트 톤의 세련된 메인 페이지와 트리 메뉴 UI 컴포넌트 코드를 작성해.

관리자가 웹에서 내용을 즉시 수정할 수 있는 편집 모드(Edit Mode) 인터페이스 초안을 보여줘.

💡 프롬프트 사용 팁 (AI 도구별)
Cursor / Windsurf 사용 시:

위 프롬프트를 입력한 후, AI가 코드를 생성하면 "기획서에 있는 RoseHA의 상세 기능(실시간 복제, 시점 복구 등)을 텍스트로 채워줘"라고 추가 요청하세요.

"반응형 UI에서 사이드바가 모바일에서는 어떻게 변하는지 보여줘"라고 요청하여 햄버거 메뉴 구현을 확인하세요.

v0 (Vercel) 사용 시:

UI 디자인 위주로 먼저 생성되므로, "화이트 톤의 IT 인프라 대시보드 스타일 홈페이지"라고 먼저 요청한 뒤 위 프롬프트의 세부 내용을 단계적으로 입력하세요.

관리자 편집 모드 구현 팁:

실제 완전한 CMS를 구축하려면 백엔드 설정이 필요하므로, AI에게 **"우선은 프론트엔드 단에서 contenteditable 속성을 활용해 실시간으로 글자가 바뀌는 시뮬레이션을 구현해달라"**고 하면 훨씬 직관적인 결과물을 바로 볼 수 있습니다.
